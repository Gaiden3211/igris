## Speaker notes

1. Say the promise in one sentence and show the live site.
2. Use one concrete question a habitat designer would ask.
3. Run the live demo here if time allows; otherwise the screenshot.
4. Stress the citation rule: no source, no claim.
5. Name the limitations: listed files are not mirrored, conditions are still being structured.
6. Tie back to the challenge objectives: relevance to crewed environments, data for modeling, next-generation controls.
7. Close with the URL.
